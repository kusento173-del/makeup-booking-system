## 已知非阻断项

- 五角色验收构建和准生产构建会出现前端单文件超过 500 KB 的体积提示，不影响当前功能；正式公网发布前应单独做按页面拆包优化。

## 验收纪律

1. 按上述顺序分阶段实现，避免多个高风险修改混在一次提交中。
2. 每一阶段至少补充对应单元测试或端到端回归。
3. 每一阶段测试通过后单独提交 Git，再继续下一阶段。
4. 涉及排班、固定关系和班次的修改必须同时验证角色权限、场地隔离和并发冲突。
