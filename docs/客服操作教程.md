# 客服操作教程

> 状态：有效｜最后更新：2026-08-06｜适用终端：电脑浏览器
>
> 本教程只说明页面怎么操作。权限边界以[角色权限矩阵](角色权限矩阵.md)为准，日期、次数、冲突和状态规则以[业务规则与状态流转](业务规则与状态流转.md)为准。

## 1. 客服负责什么

客服负责所属场地的日常排班执行：查看排班、代预约与调整、维护人员、设置固定关系与化妆师班次、处理审批、导出排班和核查操作记录。

客服只能处理自己所属场地的数据。页面即使出现其他场地名称，也不代表可以打开或修改；服务端会再次校验场地。

客服不能：

- 查看或操作其他场地的人员、预约、申请、导出和日志。
- 新增、编辑、删除管理员，或授予管理员角色。
- 修改当天预约，恢复已经取消或完成的预约，突破每日最多两次及档期冲突规则。
- 删除或修改操作记录。
- 代替运营提交固定申请；客服直接设置固定关系时走后台受控操作并填写原因。

## 2. 登录与页面结构

1. 使用单位提供的系统地址、客服账号和临时密码登录。
2. 首次登录按页面要求设置至少 12 位的新密码。
3. 进入电脑后台后，左侧一级菜单可以展开或收起：

| 一级菜单 | 页面 | 主要用途 |
|---|---|---|
| 排班管理 | 排班看板 | 查排班、代预约、改期、换化妆师、取消 |
| 排班管理 | 固定主播名单 | 查看、设置和修改固定关系 |
| 排班管理 | 排班导出 | 生成并下载本场地排班表 |
| 审批管理 | 固定申请审批 | 审核运营提交的固定新建、变更和取消 |
| 审批管理 | 班次审批 | 审核化妆师班次修改 |
| 审批管理 | 加班审批 | 审核化妆师加班 |
| 审批管理 | 请假审批 | 审核整日请假和临时不可排班 |
| 人员管理 | 主播、化妆师、运营 | 维护本场地人员和网页账号 |
| 人员管理 | 主播—运营关系 | 建立、变更和结束负责关系 |
| 系统设置 | 场地 | 查看场地；场地新增和停用仅管理员 |
| 系统设置 | 账号与角色 | 管理本站非管理员账号，管理员账号只读 |
| 系统设置 | 操作记录 | 查询本场地重要操作 |

## 3. 每日排班工作

### 3.1 查看排班

进入“排班管理 → 排班看板”：

1. 确认场地。客服场地由账号权限决定，不能切换到其他场地处理业务。
2. 选择“今天”“明天”、未来七日快捷日期或指定日期。
3. 按需要使用化妆师、主播姓名或编号、来源和状态筛选。
4. 查看每位化妆师的可排班时间、休息时间及按开始时间排序的预约。

来源含“固定”和“单次”；状态含“已预约”“已完成”“已取消”。已取消记录会保留取消原因，例如主播取消、主播请假或化妆师请假。

### 3.2 代主播预约

1. 在排班看板右上角点击“代预约”。
2. 查找并选择本场地主播，重名时必须同时核对主播编号。
3. 选择预约日期，只能选择明日起未来七日。
4. 选择妆容类型，系统自动确定时长：

| 妆容类型 | 自动时长 |
|---|---:|
| 指导妆 | 15 分钟 |
| 现代妆 | 30 分钟 |
| 特殊妆 | 45 分钟 |
| 仿妆 | 60 分钟 |

5. 选择化妆师和可用开始时间。
6. 填写代操作原因，核对主播、编号、场地、日期、时间、妆容和化妆师。
7. 提交。若是该主播当天第二次预约，确认提醒后再提交；第三次不允许创建。

提交成功后立即回到排班看板确认预约已出现。多人同时抢同一档期时，只有数据库先成功提交的一方获得档期。

### 3.3 改期、换化妆师或改变妆容

1. 在排班看板点击目标预约，先核对主播编号和原时间。
2. 选择“改期”，重新选择日期、妆容类型、化妆师和开始时间。
3. 填写修改原因并提交。

改期会取消原预约并建立新预约，不会直接改写历史。原预约仍可在历史或已取消筛选中查看。只能修改未来且未开始的预约，当天 00:00 后不可修改当天排班。

### 3.4 取消预约

1. 打开预约详情并选择“取消”。
2. 核对主播、编号、时间和实际预约化妆师。
3. 选择或填写取消原因后确认。

取消成功后档期立即释放，可被其他主播预约。取消记录和原因永久保留；系统不提供人工恢复已取消预约的按钮。

### 3.5 导出排班

1. 进入“排班管理 → 排班导出”。
2. 选择日期和本站场地，创建导出任务。
3. 等待任务完成后下载 Excel。
4. 下载后核对场地、日期、化妆师数量和预约总数，再交付现场使用。

客服只能导出所属场地，全部场地合并导出仅管理员可用。

## 4. 固定主播管理

### 4.1 审核运营提交的固定申请

进入“审批管理 → 固定申请审批”：

1. 查看申请类型：新建固定、变更固定或取消固定。
2. 核对主播姓名与编号、化妆师、场地、星期、妆容类型、开始时间、生效日期和申请原因。
3. 查看系统给出的档期结果。固定时间被其他固定关系占用时不能通过；未来存在单次预约时，应核对系统给出的最早可长期固定日期。
4. 点击通过或驳回。驳回必须写清原因。

审核时系统会重新校验，不以提交时的可用结果为准。若提示档期或数据已变化，应刷新后重新核对，不能反复点击通过。

### 4.2 客服直接设置或修改固定关系

进入“排班管理 → 固定主播名单”：

1. 点击“新增固定主播”，或在现有关系上点击“编辑”。
2. 选择本站主播和本站化妆师，重名主播必须核对编号。
3. 选择星期、妆容类型、开始时间和生效日期。
4. 填写代设或修改原因并提交。

这是客服受控纠错和补录能力，不应代替运营的正常申请流程。所有直接设置都会记录操作者、前后值和原因。

取消固定关系后，主播转为按单次预约；已生成的具体预约按取消操作和业务规则处理，空出的档期可以被其他主播预约。

## 5. 化妆师班次、加班和请假审批

### 5.1 首次代设或直接修改班次

进入“人员管理 → 化妆师”，找到目标化妆师并进入班次设置：

1. 选择每周工作日。
2. 填写上班时间、下班时间；有休息时填写休息开始和结束。
3. 选择生效日期并填写代操作原因。
4. 提交后核对化妆师可排班时间。

化妆师未设置首次班次前不能被预约。客服直接修改只能最早次日生效，不能改写当天锁定排班。

### 5.2 审核班次修改

进入“审批管理 → 班次审批”：

1. 对照当前班次与申请班次。
2. 核对工作日、上下班、休息时间、生效日期和修改原因。
3. 查看是否影响未来预约。
4. 通过或驳回；驳回必须填写可执行的原因。

### 5.3 审核加班

进入“审批管理 → 加班审批”，核对加班日期、时间、休息段和原因。通过后，加班时间才会进入可预约档期；驳回后不会改变排班。

### 5.4 审核化妆师整日请假或临时不可排班

进入“审批管理 → 请假审批”：

1. 区分“整日请假”和“临时不可排班”。
2. 核对日期、时间范围、原因和所属场地。
3. 展开受影响预约，逐条核对主播姓名、主播编号、预约时间及固定/单次类型。
4. 通过后，受影响预约统一取消并显示原因“化妆师请假”；驳回时必须填写原因。

审核通过前排班不会改变。审批完成后，审批记录保留当时的受影响预约快照，之后撤销请假或恢复符合条件的固定预约也不会改写历史快照。

化妆师在开始日前撤销已生效请假时，系统只会按规则恢复仍然有效且档期仍空闲的固定预约；已经取消的单次预约不会自动恢复。

## 6. 人员、关系和账号管理

### 6.1 人员维护

进入“人员管理”的对应页面：

- 主播：新增或编辑编号、姓名、场地；可设置“正常”或限期“取消资格”，取消资格最长一个月。
- 化妆师：新增或编辑姓名和场地；账号按 `MA` 加四位序号自动生成且不能修改。
- 运营：新增或编辑姓名和场地；账号按 `OP` 加四位序号自动生成且不能修改。

删除是业务删除：默认列表不再显示，登录和会话失效，但历史预约、审批和操作记录保留。要查已删除人员，主动选择“已删除”筛选。重新新增相同主播编号时会恢复原内部档案，不会创建断裂的历史身份。

### 6.2 建立主播—运营关系

1. 进入“人员管理 → 主播—运营关系”，点击新建关系。
2. 分别查找主播和运营，核对姓名、主播编号和场地。
3. 填写开始日期；长期关系不填结束日期。
4. 需要结束或更换运营时，先设置原关系结束日期，再建立新关系，避免日期重叠。

运营只能查看和操作目标日期关系有效的主播。第一批导入关系可以没有开始日期，表示导入时已经生效。

### 6.3 账号与角色

进入“系统设置 → 账号与角色”：

- 可按角色、账号状态和关键词筛选。
- 可开通或重置本站非管理员账号的临时密码。
- 可创建本站客服账号、维护允许的本站角色。
- 管理员账号只读，不能编辑、删除、重置密码或改变角色。

重置密码后，用户所有已登录设备会退出；把临时密码安全交给本人，并提醒首次登录立即修改。禁止在群聊或公开表格中长期保存密码。

## 7. 操作记录与交接

“系统设置 → 操作记录”用于核查谁在什么时间对什么对象做了什么。处理争议时：

1. 先按时间、操作类型或对象搜索。
2. 核对操作账号、当时使用的角色、修改前后值和原因。
3. 不要通过再次修改业务数据来“抹平”记录；需要纠错时按正常流程操作并填写原因。

交班前至少确认：次日待审批清零或已说明、次日排班已检查、异常取消原因明确、导出文件日期场地正确、临时密码已经单独交付。

## 8. 常见提示怎么处理

| 页面提示 | 常见原因 | 正确处理 |
|---|---|---|
| 请求内容不正确 | 必填项、日期、时间或对象不符合规则 | 核对页面全部字段，不要连续重复提交 |
| 数据已变化，请刷新后重试 | 其他人刚修改了同一条数据 | 刷新页面，重新查看最新状态再操作 |
| 档期已被占用 | 有人先完成同一化妆师同一时段预约 | 选择新的化妆师或时间 |
| 无权访问 | 目标不在本站，或账号角色不允许该动作 | 核对场地和当前角色；不要修改网址绕过 |
| 当天排班已锁定 | 目标日期已经到 00:00 | 系统内不再操作，按线下应急流程处理；管理员也不能突破锁定规则 |
| 登录失效 | 密码被重置、账号被删除或会话过期 | 返回登录页重新登录；仍失败则联系管理员 |

出现异常时应记录页面、时间、主播编号、预约日期和操作步骤，不要记录或发送密码。
