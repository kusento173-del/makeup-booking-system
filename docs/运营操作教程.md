# 运营操作教程

> 状态：有效｜最后更新：2026-08-06｜适用终端：手机浏览器、微信内置浏览器
>
> 本教程说明运营如何为负责主播操作。权限以[角色权限矩阵](角色权限矩阵.md)为准，预约与固定的精确规则以[业务规则与状态流转](业务规则与状态流转.md)为准。

## 1. 你能做什么

运营可以查看当前负责主播及其排班、为目标日期关系有效的主播代预约、改期或取消，并提交固定关系的新建、变更和取消申请。

运营不能：

- 查看或操作不由自己负责、关系已结束或尚未分配给自己的主播。
- 修改主播人员资料、预约资格、化妆师班次、加班或请假。
- 审批固定、班次、加班或请假申请。
- 直接建立固定关系；固定操作必须经客服或管理员审核。
- 突破当天锁定、未来七日、每日最多两次、同场地和档期冲突规则。

## 2. 首次登录与个人信息

1. 打开单位提供的系统网址。
2. 输入以 `OP` 开头的运营账号和临时密码。
3. 首次登录必须设置至少 12 位的新密码。
4. 进入“我的”核对姓名、身份、场地和账号。

运营账号由系统按顺序生成，不能改成姓名或手机号。姓名或场地错误时联系客户服务修改人员档案；不要自行借用其他运营账号。

## 3. 负责主播

进入“首页 → 负责主播”：

1. 选择目标日期。
2. 查看当天由你负责的主播；重名时以主播编号为准。
3. 每位主播会显示场地、预约资格、当前固定化妆师或固定规则，以及待审核固定申请。
4. 点击“代预约”进入该主播预约页面。

主播—运营关系只有开始日期和结束日期；长期负责关系没有结束日期。页面上的目标日期只用于判断那一天你是否有权为该主播操作，不是关系表中的额外字段。

第一批导入关系没有开始日期时，表示导入时已经生效。关系结束后，该主播不再出现在当前负责名单中，你也不能继续打开其资料或操作未来预约。

## 4. 为主播预约

### 4.1 新建预约

进入“代主播预约”，按以下顺序操作：

1. 选择预约日期，只能选择明日起未来七日。
2. 选择负责主播，核对姓名、编号和场地。
3. 选择妆容类型：

| 妆容类型 | 自动时长 |
|---|---:|
| 指导妆 | 15 分钟 |
| 现代妆 | 30 分钟 |
| 特殊妆 | 45 分钟 |
| 仿妆 | 60 分钟 |

4. 选择同场地化妆师。
5. 从系统返回的空闲档期中选择开始时间。
6. 核对全部信息并提交。

系统自动检查化妆师班次、休息、非工作日、加班、请假、临时不可排班和已有预约。无法选择的时间不应通过反复刷新或更换设备绕过。

同一主播一天最多两次预约。第二次提交前会明确提醒，确认确有需要后才继续；第三次无法创建。固定预约和单次预约都计入当天次数。

### 4.2 改期或换化妆师

1. 进入“排班”，找到负责主播的未来“已预约”记录。
2. 点击预约并选择“改期”。
3. 重新选择日期、妆容类型、化妆师和时间后提交。

改期会取消原预约并创建新预约，原记录仍以“已取消”保留。固定预约临时改到同一化妆师的不同时间，或换到其他化妆师，都按单次预约展示；长期固定规则本身不会因此改变。

### 4.3 取消预约

1. 打开未来“已预约”记录并点击“取消”。
2. 核对主播编号、日期和时间后确认。

取消后档期立即释放给其他主播。取消固定生成的某一天预约只影响当天实例，不等于取消长期固定关系。

## 5. 查看排班

从底部进入“排班”，可查看今日、明日、未来七日和历史。运营只看到当前负责范围内主播的记录。

排班显示主播、编号、日期时间、实际预约化妆师、场地、妆容类型、固定/单次来源和状态。历史单次查询最多 31 天。取消记录会显示取消原因。

如果关系刚刚建立、结束或变更，刷新页面后再查；系统以数据库中目标日期有效关系为准，不以手机缓存为准。

## 6. 固定申请

固定相关操作只能由运营发起，客服或管理员审核后生效。

### 6.1 新建固定申请

1. 进入“首页 → 固定申请”。
2. 选择当前负责主播，核对编号和场地。
3. 选择化妆师、每周星期、妆容类型和期望生效日期。
4. 查看系统给出的可固定时间，选择开始时间。
5. 填写申请原因并提交。

固定时间选择逻辑：

- 已被其他固定关系占用的时间不能选择。
- 未来存在单次预约时，系统会给出该时间可以连续固定的最早日期；生效日期必须不早于它。
- 审核时系统会再次校验，提交成功不代表一定通过。

### 6.2 变更固定

选择已有固定的主播后，页面会显示当前化妆师、星期、时间、妆容和生效情况。修改所需字段、选择生效日期并填写原因后提交。

变更固定星期、时间、化妆师或妆容都需要审批。在申请通过前，原固定关系继续有效。

### 6.3 取消固定

1. 选择已有固定关系。
2. 点击取消固定，填写取消原因并再次确认。
3. 等待审批。

通过后长期固定关系结束，主播变为单次预约；系统没有“暂停固定”功能。只想取消某一天时，应在排班中取消那一天的预约，不要提交取消固定。

### 6.4 撤回申请和查看状态

待审核申请可以撤回。已通过、已驳回或已撤回的申请不能再次处理；需要改变时重新提交新申请。

| 状态 | 含义 |
|---|---|
| 待审核 | 客服或管理员尚未处理，当前固定不变 |
| 已通过 | 按申请内容和生效日期执行 |
| 已驳回 | 不生效；查看审核意见后重新申请 |
| 已撤回 | 申请人主动终止本次申请 |

## 7. 主播请假与化妆师请假对运营的影响

主播请假由主播本人提交。请假范围内该主播的固定和单次预约会取消；运营可以在排班中查看结果，但不能代主播提交或撤销请假。

化妆师请假和临时不可排班由化妆师提交并等待审批。通过后，受影响预约显示“已取消 / 化妆师请假”，释放的档期可重新预约其他可用化妆师。

请假撤销后，符合条件的固定预约可能按规则恢复；单次预约不会自动恢复。运营应刷新排班确认实际状态后再决定是否重新预约，不能只根据聊天消息判断。

## 8. 常见提示怎么处理

| 页面提示 | 常见原因 | 正确处理 |
|---|---|---|
| 无权访问 | 主播不在当前或目标日期负责范围 | 核对主播—运营关系，联系客户服务维护关系 |
| 请求内容不正确 | 日期、时间、必填项或对象不符合规则 | 返回页面逐项检查，不要连续重复提交 |
| 数据已变化，请刷新后重试 | 预约、固定或负责关系刚被其他人更新 | 刷新后以最新页面为准重新操作 |
| 档期已被占用 | 其他人先完成同一档期预约 | 选择其他时间或化妆师 |
| 当天排班已锁定 | 已到目标日期 00:00 | 不能新增、改期或取消当天预约 |
| 主播预约资格不可用 | 主播处于限期取消资格或已删除 | 联系客户服务核对，不要换账号代约 |
| 已达到每日上限 | 主播当天已经有两次预约 | 不再创建第三次预约 |

## 9. 每日使用清单

预约前：核对主播编号、场地、目标日期关系和预约资格。

提交后：立即在排班中确认日期、时间、妆容和实际预约化妆师。

每天结束前：查看负责主播次日排班，尤其关注无预约、取消、请假及待审核固定申请。系统不发送微信通知，最终结果以网页为准。

发现异常时记录主播编号、日期时间、页面提示和操作步骤并交给客户服务；不要发送密码或尝试操作他人账号。
