# 化妆师操作教程

> 状态：有效｜最后更新：2026-08-06｜适用终端：手机浏览器、微信内置浏览器
>
> 本教程说明化妆师本人如何使用系统。权限边界以[角色权限矩阵](角色权限矩阵.md)为准，精确排班规则以[业务规则与状态流转](业务规则与状态流转.md)为准。

## 1. 你能做什么

化妆师可以查看个人信息、本人固定主播、本人排班和历史，首次设置固定班次，提交班次修改、加班、整日请假和临时不可排班申请，并查看申请结果。

化妆师不能替主播预约、改期或取消，不能查看其他化妆师的完整排班，不能批准自己的申请，也不能直接修改已经锁定的排班。

## 2. 首次登录

1. 打开单位提供的系统网址。
2. 输入以 `MA` 开头的化妆师账号和临时密码。
3. 首次登录必须设置至少 12 位的新密码，不能继续使用临时密码。
4. 进入“我的”核对姓名、身份、场地和登录账号。信息不正确时联系所属场地客服，不要自行借用他人账号。
5. 如果首页持续提醒未设置班次，先完成首次班次设置；未设置前不会出现在可预约化妆师中。

同一账号可以在不同设备登录；密码被客服或管理员重置后，所有旧设备会退出。

## 3. 查看排班

从底部进入“排班”，可切换：

- 今天：当天只读排班。
- 明天：次日排班。
- 未来七日：当前可预约范围内的排班。
- 历史：按日期查询过去记录，单次查询最多 31 天。

每条排班显示主播姓名与编号、日期、开始与结束时间、场地、妆容类型、固定/单次来源和状态。已取消记录还会显示取消原因。

妆容类型与时长固定对应：指导妆 15 分钟、现代妆 30 分钟、特殊妆 45 分钟、仿妆 60 分钟。

化妆师端排班只用于查看，不能直接改动。发现主播、时间或状态错误时，把主播编号、日期和时间发给客服核查。

## 4. 班次设置与修改

### 4.1 首次设置班次

进入“首页 → 班次”或底部“班次”：

1. 勾选每周工作日；未勾选的星期默认不可预约。
2. 填写上班时间和下班时间。
3. 有固定休息时填写休息开始、休息结束；没有休息可留空。
4. 核对后点击“保存首次班次”。

保存成功后页面会显示当前工作日、上下班时间、休息时间和生效日期。首次班次直接生效，不需要审批。

### 4.2 修改已有班次

1. 在班次页先查看“当前班次”，不要只看表单默认值。
2. 修改工作日、上下班或休息时间。
3. 选择生效日期，最早为次日。
4. 填写真实、明确的修改原因。
5. 点击“提交修改申请”。

提交后“最近一次修改申请”会显示状态：

| 状态 | 含义 | 可以做什么 |
|---|---|---|
| 待审核 | 客服或管理员尚未处理 | 可撤回；不要重复提交 |
| 已通过 | 新班次将在生效日生效 | 核对生效日期和班次详情 |
| 已驳回 | 不会改变当前班次 | 查看审核意见，修改后重新申请 |
| 已撤回 | 本次申请作废 | 需要时重新提交 |

页面出现“数据已变化，请刷新后重试”表示申请或班次刚被其他流程更新。刷新后先看最新状态，再决定是否重新提交。

## 5. 加班

加班用于在原本非工作日或正常班次之外开放可预约时间。

1. 进入“首页 → 加班”。
2. 选择明日起未来七日内的日期。
3. 填写加班开始、结束时间；需要休息时填写休息段。
4. 填写原因并提交。

加班申请通过后才产生可预约档期。待审核申请可以撤回；已经通过的加班需要变更时联系所属场地客服，不能直接覆盖旧记录。

## 6. 整日请假

整日请假适用于某一天或连续几天完全不能工作：

1. 进入“首页 → 请假”。
2. 选择开始日期和结束日期，必须在明日起未来七日内，连续天数最多七天。
3. 填写原因；提交前查看受影响预约数量。
4. 确认后提交，等待客服或管理员审核。

审核通过后，范围内固定和单次预约都会取消，取消原因显示“化妆师请假”。审核前排班不会变化。

待审核或尚未开始的有效请假可以撤销。撤销已经生效的化妆师请假时，系统只尝试恢复仍有效、档期仍空闲的固定预约；单次预约不会自动恢复，需由主播或运营重新预约。

## 7. 临时不可排班

临时不可排班用于某一天只有部分时间不能工作，例如上课、开会或临时事务。它不是整日请假。

1. 进入“首页 → 临时不可排班”。
2. 选择明日起未来七日内的日期。
3. 填写不可排班开始和结束时间。
4. 填写原因，查看受影响预约数量。
5. 确认并提交，等待审批。

审核通过后，重叠的固定和单次预约会取消，并统一显示取消原因“化妆师请假”；该时段也不再可约。其他未重叠时段继续正常开放。

待审核或尚未开始的有效时段可以撤销。撤销不会恢复已经取消的单次预约。

## 8. 固定主播名单

首页“固定主播名单”展示当前与你有效固定的主播，包括主播姓名、编号、星期、时间和妆容类型。化妆师只能查看，不能自行新建、变更或取消固定关系。

发现固定主播或时间不正确时，联系运营发起固定变更申请，或联系所属场地客服核查。不要用班次修改来代替固定关系变更。

## 9. 常见情况

| 情况 | 处理方式 |
|---|---|
| 班次页没有当前班次 | 完成首次班次设置；保存后刷新一次 |
| 提交按钮无反应 | 检查日期、开始结束时间、原因和网络；避免快速连点 |
| 请求内容不正确 | 通常是日期超范围、结束早于开始或必填项为空，逐项核对 |
| 数据已变化，请刷新后重试 | 刷新并查看最新申请状态，不要在旧页面重复提交 |
| 排班突然显示已取消 | 查看取消原因；“化妆师请假”通常来自已批准请假或不可排班 |
| 登录失效 | 账号密码被重置、人员被删除或会话过期，重新登录或联系客户服务 |
| 需要当天请假 | 化妆师本人不能在当天新增；立即联系所属场地客服按现场制度处理 |

## 10. 每日使用清单

上班前：查看今日排班和变动，核对第一位主播及开始时间。

下班前：查看明日排班；有未来七日内请假、上课或加班安排时尽早提交，避免已有预约受影响。

离职、调场地或姓名错误：联系客户服务处理人员档案，不要注册或借用第二个账号。
