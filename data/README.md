# 本地数据目录说明

`data/` 用于保存开发、迁移和核对过程中使用的数据文件。该目录中的人员明细属于敏感数据，不能提交到 Git 或发送到公共代码仓库。

## 目录

```text
data/
├─ README.md
└─ source/       # 当前五张Excel源文件，已被Git忽略
```

## 当前文件职责

- `线下主播人员表.xlsx`：首次迁移的主播主档来源。
- `化妆师人员表.xlsx`：首次迁移的化妆师主档来源。
- `运营人员表.xlsx`：首次迁移的运营主档来源。
- `主播与运营对应表.xlsx`：能精确匹配的关系进入系统，无法匹配的运营留空。
- `化妆师固定主播名单.xlsx`：只作历史参考，不导入数据库、不生成固定预约。

## 安全规则

- 不在 Markdown、代码、日志或 Git 提交中复制人员姓名、编号等明细。
- 导入错误报告和清洗中间文件放在 `data/private/` 或 `data/processed/`，这两个目录同样被 Git 忽略。
- 如需共享数据，先脱敏并确认接收范围。
- 修改源文件后必须重新运行数据预检，不能沿用旧文件的统计结论。
