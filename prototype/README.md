# 妆序交互原型

化妆部预约系统第一阶段可点击原型，用于在正式业务代码开发前确认角色、页面、操作路径和关键提示。

## 原型范围

- 主播：查看排班、创建第一次与第二次预约、改期和取消。
- 运营：查看负责主播、代预约、查看固定时间并提交固定申请。
- 化妆师：首次班次设置、查看个人排班、请假影响确认。
- 客服：本场地排班时间轴、代录、固定审批、人员查询和导出。

所有页面使用模拟数据，不包含项目 data/source 中的真实人员名单。

## 本地运行

要求 Node.js 22.13 或更高版本。

1. 安装依赖：npm install
2. 启动预览：npm run dev
3. 运行测试：npm test
4. 运行代码检查：npm run lint

## 代码结构

- app/prototype.tsx：原型状态和业务交互。
- app/globals.css：视觉系统和响应式布局。
- app/layout.tsx：页面元数据和分享卡片配置。
- tests/rendered-html.test.mjs：基础服务端渲染测试。
- public/og.png：原型分享卡片。

本原型不是生产预约系统，不连接人员数据库、微信通知或真实审批。
